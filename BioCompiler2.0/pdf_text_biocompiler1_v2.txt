                                               Biocompiler 1.0

                                         DNA Transcriber — Especificação da Atividade

Objetivo: receber uma sequência de DNA e simular, de forma didática, sua análise e transcrição
até a geração de um pré-mRNA.

1. Papel do BioCompiler 1.0

Entrada: sequência de DNA.

Processamento: validação da sequência, identificação da região codificante e transcrição do DNA
em pré-mRNA.

Saída: pré-mRNA, quando a entrada for válida; caso contrário, um diagnóstico do problema.

Fase I: DNA transcrito em pré-mRNA — BioCompiler 1.0 (objeto deste trabalho)
Fase II: pré-mRNA amadurecido em mRNA maduro — BioCompiler 2.0
Fase III: mRNA traduzido em proteína — Sr. Ribossomo (trabalho futuro)

2. Formato de entrada

A entrada será um arquivo texto (.txt) contendo uma ou mais sequências de DNA. Cada linha do
arquivo corresponde a uma sequência independente. O programa deverá processar as linhas na
ordem em que aparecem no arquivo.

Cada sequência deverá utilizar apenas A, T, C e G, sem espaços ou separadores internos.

Exemplo

Nome: arquivo entrada.txt

CCCATGGCTAAACCGTAA
GGGATGCCCGGGTAG
TTTATGAAACCCGGGTGA

3. Convenção didática para análise da sequência

Para tornar o problema implementável e corrigível automaticamente, o BioCompiler 1.0 usará
uma gramática simplificada. Ela representa conceitos reais da expressão gênica, mas não
pretende reproduzir toda a complexidade biológica.

REGIÃO CODIFICANTE VÁLIDA: ATG ... TAA / TAG / TGA

Elemento         Representação           Função didática
START            ATG                     Marca o início da região
                 trincas de A/T/C/G      codificante.
Códons internos  TAA, TAG ou TGA         Mantêm a leitura em grupos
                                         de três bases.
STOP                                  1  Marca o término da região
                                         codificante.

4. Regra de identificação da região codificante

Para a atividade, o programa deverá localizar o primeiro ATG válido e, a partir dele, ler a sequência
em trincas. O término válido será o primeiro códon TAA, TAG ou TGA encontrado no mesmo
quadro de leitura.

Bases antes do ATG e depois do STOP podem existir e não fazem parte da região codificante usada
para a validação do quadro de leitura.

5. Operação de transcrição

Quando a sequência for considerada válida, o programa deverá transcrever o DNA para pré-mRNA
substituindo cada timina (T) por uracila (U), preservando a ordem das demais bases.

DNA: ATGGCTAAACCGTAA
pré-mRNA: AUGGCUAAACCGUAA

6. Convenção didática para frameshift

Para esta atividade, será classificado como frameshift o caso em que, após o ATG, a região
analisada não puder ser organizada integralmente em trincas até o término esperado. Essa é uma
convenção computacional do exercício.
Observação: biologicamente, a identificação inequívoca de uma mutação frameshift exige
comparação com uma sequência de referência. Aqui, o termo é usado segundo a regra didática
acima.

7. Convenção didática para nonsense / STOP prematuro

Para a atividade, será considerado STOP prematuro quando surgir um códon TAA, TAG ou TGA em
fase antes do término esperado da região codificante, havendo ainda sequência codificante após
esse ponto. Essa é uma convenção didática criada para permitir classificação automática
Observação: biologicamente, determinar que um STOP é prematuro também requer contexto ou
sequência de referência. No BioCompiler 1.0, prevalece a convenção estabelecida no exercício.

8. Casos que o programa deverá reconhecer

Caso  Situação                                        Resposta esperada
1     Sequência válida                                CORRETO
2     Presença de caractere diferente de A,           BUG - base inválida
      T, C ou G
3     ATG de início ausente                           BUG - START ausente
4     STOP válido ausente                             BUG - STOP ausente
5     Quadro de leitura incompatível com              BUG - frameshift
      trincas segundo a convenção
6     STOP em fase antes do término                   BUG - nonsense / STOP prematuro
      esperado

9. Saída padrão para a tela

A saída exibida na tela será detalhada e destinada ao usuário. Para cada linha, o programa
mostrará o número da entrada, o status, o diagnóstico e, quando aplicável, o pré-mRNA.

========================================
BIOCOMPILER 1.0 - DNA TRANSCRIBER
========================================
ENTRADA: 1
STATUS: CORRETO
Bases: OK
START: ATG - OK
Quadro de leitura: OK
STOP: OK
Transcrição: OK
pré-mRNA: AUGGCUAAACCGUAA
----------------------------------------

10. Processamento em lote

O arquivo poderá conter uma ou várias linhas. O programa deverá processar cada linha de forma
independente, preservar a ordem das entradas e gerar um resultado correspondente para cada
uma delas.

11. Saída padrão para arquivo exportado

Além da saída na tela, o programa deverá gerar um arquivo de resultados. Para facilitar a correção
automática, recomenda-se um registro por linha, com campos separados por ponto e vírgula.

linha;status;resultado;pre_mRNA
1;OK;CORRETO;AUGGCUAAACCGUAA
2;ERRO;BUG - base inválida;NÃO GERADO
3;ERRO;BUG - START ausente;NÃO GERADO

Padrão proposto: arquivo resultados.txt (ou .csv, se desejado), codificação UTF-8. Os textos da
coluna 'resultado' devem ser reproduzidos exatamente como definidos na especificação.

12. Requisitos de implementação

• Linguagens aceitas: Java ou Python.
• O programa deve ler as entradas a partir de arquivo texto.
• Uma entrada por linha.
• Não assumir previamente qual caso está sendo analisado.
• Não utilizar separadores internos na sequência de entrada.
• O BioCompiler 1.0 termina no pré-mRNA; ele não realiza maturação do RNA nem tradução de

     proteínas.

13. Resumo do algoritmo

          LER linha
             ↓

          VALIDAR caracteres A/T/C/G
             ↓

          LOCALIZAR START (ATG)
             ↓

          ANALISAR quadro de leitura em trincas
             ↓

          LOCALIZAR e VALIDAR STOP
             ↓

          CLASSIFICAR a sequência
             ↓

          SE CORRETA: TRANSCREVER T → U
             ↓

          GERAR pré-mRNA + RELATÓRIO

Princípio da atividade: o aluno deve implementar um analisador molecular, não memorizar casos
de teste.

Suponha um arquivo de entrada com SEIS linhas, cada linha correspondendo a uma sequência de
DNA. A primeira é válida e as demais representam, didaticamente, cada uma das situações que o
BioCompiler 1.0 deverá reconhecer. A seguir são mostradas a saída na tela e a forma
correspondente no arquivo exportado.

          Bases: OK
          START: ATG - OK
          Quadro de leitura: OK
          STOP: TAA - OK
          Transcrição: OK
          pré-mRNA: AUGGCUAAACCGUAA

          1;OK;CORRETO;AUGGCUAAACCGUAA
